# Group 6 — Productivity

Only features tied to a work item (ticket or PR). Generic notes, snippets,
bookmarks and TODOs are left to VS Code snippets and existing extensions.
Surfaces: card actions, Home, status bar. See `roadmap.md`.

## Add (in priority order)

1. **"Now working on" pin** — pin one ticket or PR; show its key in the status
   bar. Manual first; automatic once current-branch detection exists
   (`workflow-backlog.md` #4).
2. **Follow-up list** — personal checklist built from comments awaiting your reply
   (`dashboard-backlog.md` #1). Not a general TODO scanner.
3. **Per-ticket notes** — a short private note on a card, stored locally.
4. **Worklog text helper** — copy a time-entry line for the ticket you worked on.
   Copy only; no Jira write.

## Not planned

- Generic notes app, snippet manager, bookmarks, TODO-comment scanning.
- Writing worklogs or transitions to Jira (conflicts with "no full Jira client").

- Should notes sync across machines, or stay local to one editor profile?
