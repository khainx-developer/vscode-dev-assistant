# Backlog

Ideas considered but not currently prioritized. Not scoped or scheduled — revisit when there's room.

## Notifications
Native VSCode notification/toast when a *new* item lands in the Attention Inbox (not just the next time the dashboard is opened), so a changes-requested or failing-check doesn't sit unseen for hours.

## Snooze
Let a user dismiss an attention item for a set period ("remind me tomorrow") without fully resolving it, so items they've seen but can't act on yet stop cluttering the top of the inbox.

## Inline quick actions
Approve/comment/merge a PR, or transition a Jira ticket's status, directly from a dashboard card — avoiding a context switch to the browser for common actions.

## Daily standup generator
Use the existing `engineering:standup` skill, fed from this extension's monitored PRs/tickets, to generate a one-click "yesterday/today/blockers" summary.
