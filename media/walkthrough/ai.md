# Ask AI what to do next (optional)

DevMate uses the **language models already available in your editor** through the VS Code Language Model API — for example GitHub Copilot, or Claude when your Copilot plan or another installed provider offers it.

- **Ask AI: What should I do next?** turns your inbox into a short, prioritized plan.
- **Generate Standup Summary** writes Yesterday / Today / Blockers you can paste into chat.
- **Explain** on any inbox item says why it's flagged and what to do.

DevMate sends only titles, statuses, reasons and short comment excerpts — never tokens or credentials — and stores no API keys of its own.
